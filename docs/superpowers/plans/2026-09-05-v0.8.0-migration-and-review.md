# v0.8.0「迁移与回顾」Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> 主会话内联执行（executing-plans 模式）。

**Goal:** FR-STORE-06（Obsidian/Foam/纯 md 目录导入，wikilink→OKF 链接）+ FR-LLM-07（每日/每周回顾）+ FR-MODEL-05（LLM 用量记录与展示）+ 全局热键可配置（v0.7 实测发现）。

**Architecture:** 导入器纯逻辑（链接转换/frontmatter 映射/路径规划）放 core 可测层，IO 编排在壳层（std::fs 豁免区）内存内两阶段（plan→write），二进制复用 `archive_binary`；用量记录用**包装器 Provider**（`llm_config::build()` 注册时包裹，单一挂点覆盖 indexer/chat/转录/视觉全部调用，事件经回调 sink 批写 SQLite）；回顾复用 summarize 路由 + ADR-0005 护栏。

**Tech Stack:** Rust（lmnotes-core + 壳）/ SolidJS。

## 关键现状（已核实 2026-09-05）

- `import_note`（commands.rs:1725）是单文件 md 导入：已有 frontmatter 补 id，无则生成 `type: note`——Obsidian 导入的 frontmatter 容错起点。
- Provider 按能力拆 trait（ChatCap/EmbedCap/TranscribeCap/VisionCap，provider.rs），Registry 按能力 HashMap 注册、id 路由（routing.rs:33）→ 包装器在 `llm_config::build()` 挂一层即可全覆盖（indexer/mod.rs:219/262/289、retriever、transcribe_fallback、shell chat/rewrite 全走 Registry）。
- `archive_binary(data, ext, kind)`（commands.rs:193）：sha256 分桶归档，assets 导入直接复用。
- 回顾生成可复用 shell 内已有 chat helper（commands.rs:377 一带，rewrite/extract 同源，含护栏检查）。
- Config 结构在 `llm_config.rs`（serde 默认兼容旧文件——加 `capture.hotkey` 用 `#[serde(default)]`）。
- 时间范围笔记：`list_timeline(limit)` 已按 mtime 倒序，回顾在壳层过滤 `mtime >= since` 即可，无需新 core 查询。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 大库导入内存占用 | v1 全内存（手册注明）；图片走 bytes 分文件读，不叠加持有 |
| wikilink 歧义（同名笔记） | 精确路径优先，其次唯一 title，多义→未解析保留原文+warning |
| Recording 包装器 trait 对象化 | 泛型 `Recording<P: ChatCap>` + `register_*_arc` 现成泛型位 |
| 回顾 LLM 无健康 provider | 命令返回指引性错误（与 chat 一致），UI toast 呈现 |
| 热键非法串 | 注册失败日志 + 设置页校验提示，不阻塞启动 |

## 手动验证清单

1. 假 Obsidian 目录（2 笔记互链 + 1 图 + 中文文件名 + tags 字符串 frontmatter）→ dry-run 报告正确 → 执行后：笔记落 `notes/import-<date>/`、链接成 OKF 路径、图在 `assets/img/`、搜索/图谱可见。
2. 命令面板「每日回顾」→ 生成 review 笔记并打开；无 provider 时友好报错。
3. 设置页用量表：本地/云端分组计数，做一次 chat 后计数 +1。
4. 热键改为 Ctrl+Shift+K → 重启后新热键注册成功（日志）。

## 明确不做（本版）

- Foam/Logseq 等 `.md` 之外格式特判（纯 md + wikilink 通吃即覆盖 Foam）。
- 定时自动回顾（手动触发先行）。
- 导入冲突的高级合并策略（同名去重后缀 + 报告提示足够）。
- token 精确计量（chars/4 估算，标注"估算"）。
