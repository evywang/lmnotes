## 关键现状（已核实 2026-09-05）

- `TantivyIndex::search` 已返回 `body_snippet`（整段 body，未截窗）——前端可自行截窗高亮，core 只需提供纯函数 `make_snippet`。
- `search::rrf::fuse_scores` 已存在（retriever 内按 rank 累加 1/(k+rank)）——融合编排可循 qa/retriever.rs:48-85 模式，但那是 chunk 级、私有；本版在 core 新增**笔记级** `hybrid_fuse` 纯函数供壳层复用。
- `SearchEngine::search`（BM25+元数据富化）与 `SqliteIndex::vector_search(q, k)` 均现成；embed 由壳层 Registry（Task::Embed 路由）发起。
- ChatDrawer：`ask()` 读 `input()` signal——加 `pendingQuestion` prop + createEffect 即可外部触发提问。
- `export_vault_zip` 的 zip 循环可抽 `zip_vault_to(root, dest, progress)` 复用（collect_export_files 已排除 `.lmnotes/`）。
- tauri.conf.json bundle icons 齐全（托盘图标用 default_window_icon）。

## 风险与对策

| 风险 | 对策 |
|---|---|
| embed 请求慢拖累侧栏搜索 | embed 设 3s 超时，超时/失败即降级 BM25（不阻塞） |
| 高亮 XSS | 不用 innerHTML——Solid 切片数组渲染纯文本节点 |
| tray-icon 跨平台差异 | 统一用菜单交互（右键菜单 + 左键显示主窗），不依赖平台独有行为 |
| 备份 zip 大库耗时 | spawn_blocking + 启动首跑延迟 2 分钟避开索引高峰 |

## 手动验证清单（托盘部分需真人）

1. 侧栏中文短词（如「注意」）能命中原分词「注意力」的笔记（向量路兜住）且带高亮片段。
2. Ctrl+K 输入问题 → 「问 LMNotes」→ Chat 打开并自动发送流式回答。
3. 关闭主窗 → 托盘常驻（热键仍可唤起浮窗）；托盘「退出」才真正退出；开机自启开关生效。
4. 手动「立即备份」→ dest 出现带时间戳 zip；keep=2 再备份两次 → 只剩 2 个。
