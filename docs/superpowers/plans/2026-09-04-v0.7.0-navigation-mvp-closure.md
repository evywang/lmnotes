## 风险与对策

| 风险 | 对策 |
|---|---|
| global-shortcut 权限名随插件版本变化 | 以 `gen/schemas` 报错提示为准逐个补；dev 冒烟 |
| 老库无 tags 列 | ALTER 容错迁移（aliases 同款），默认 `'[]'` 不破坏旧行 |
| 浮窗与主窗口共享 dist 路由 | hash 路由分流，main.tsx 单点判断 |
| 快捷键与系统/输入法冲突 | 选 `CmdOrCtrl+Shift+L` 避开 Alt+Shift（Win 输入法切换）；常量易改 |
| tags JSON 聚合性能 | 个人库万篇级，全表读 Rust 聚合 <50ms；不建倒排表（YAGNI） |
