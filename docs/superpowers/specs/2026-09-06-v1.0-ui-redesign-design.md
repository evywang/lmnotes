# LMNotes v1.0 界面重设计 —「石墨」设计系统

- 日期：2026-09-06
- 状态：待用户审阅
- 范围：`apps/desktop` 前端（SolidJS + styles.css）+ 主题引擎所需的一个 Tauri shell 只读命令（`list_themes`）；其余 Rust 侧不变
- 已确认决策：分期实现；布局模型 A（导航栏 + 上下文栏）；视觉方向「石墨冷静」（暗色优先、中性面板、单一强调色）；增补：主题插件化 + 运行时动态切换（见 §4.3）

---

## 1. 背景与问题诊断

当前 UI（v0.9）功能齐全但组织失序，核心问题：

| # | 问题 | 证据 |
|---|------|------|
| 1 | 侧栏超载、无层级 | 搜索框 + 3 操作按钮 + 库徽标 + 任务入口 + **4 个通栏实心按钮**（Chat/图谱/今日/时间线）+ 标签云 + 结果列表 + 底部折叠文件树，全部同权堆叠 |
| 2 | 三种列表模型互斥竞争 | 搜索结果、文件树（默认折叠藏在列表下方）、标签云共用一列 |
| 3 | 右栏永久占用 | 建议中心固定 260px，为空也占屏 |
| 4 | 无顶栏锚点 | 笔记无标题/面包屑上下文；⚙ 设置按钮 fixed 漂浮右下角，与任何分区无关 |
| 5 | 令牌体系缺失 | 仅 6 个颜色变量；无间距/字阶/圆角/阴影/状态色/动效/焦点规范 |
| 6 | Emoji 当图标 | 📚💬🕸🕘⚙ 跨平台渲染不一致 |
| 7 | 浮层规格各自为政 | 三套遮罩（z100/z300/抽屉 z50-101），宽度 340/420/560/600/620/640 混用；Esc/✕/确认/错误反馈不统一 |
| 8 | AI 入口碎片化 | "LLM 原生"应用的 AI 能力散落在 4 个并列按钮、编辑器右键、右栏、命令面板，无统一心智模型 |

## 2. 设计原则（AI 时代笔记软件）

1. **内容为王，AI 在场而不喧哗** —— 编辑区是舞台；AI 通过一个一致的「✦」符号与一个提问入口出现，绝不用 N 个等权按钮竞争注意力。
2. **一个分区只回答一个问题** —— 我要去哪（导航栏）／我要找什么、收什么（上下文栏）／我在读什么写什么（主区+顶栏）／我在审什么（右面板）／我在专注做什么（浮层）。
3. **列表即导航** —— 搜索结果、最近笔记、文件树是同一组件的三种视图，不是三个区块。
4. **键盘可达一切** —— ⌘K 是万能入口；所有浮层 Esc 可关；焦点可见。
5. **少做一个决定** —— 危险操作统一确认样式；失败必有 toast；空/加载/错误状态是设计对象而非事后补丁。

### 3.1 导航栏（Rail，48px）

图标-only 垂直导航，自上而下 = 使用频率：

| 图标 | 名称 | 行为 | 快捷键 |
|------|------|------|--------|
| ✎ | 笔记 | 聚焦上下文栏列表（应用默认态） | ⌘1 |
| 📅 | 今日 | 打开/创建今日 daily note（动作） | ⌘D |
| 🕘 | 时间线 | 打开时间线浮层 | — |
| 🕸 | 知识图谱 | 打开图谱抽屉 | ⌘G |
| ✦ | 问 LMNotes | 打开问答抽屉 | ⌘J |
| ⏳ | 媒体任务 | 打开任务浮层（徽标显示运行中数量） | — |
| ⚙ | 设置（底部） | 打开设置 | ⌘, |
| 📚 | 库指示（底部） | 小圆点+库名首字，点击 → 设置·库分区 | — |

规范：48×48 热区；激活态 = 24×24 圆角 6px 的 `--surface-active` 底 + 强调色前景；非激活 = `--text-2`，hover 提亮；tooltip（150ms 延迟）显示「名称 + 快捷键」。浮层打开期间对应图标保持激活态。

### 3.2 上下文栏（Context，288px）

**回答「找与收」**。自上而下四段：

1. **搜索框**（高 32px，圆角 6）：占位「搜索或提问…」，右侧内嵌 ⌘K 角标。**实时搜索**（300ms 防抖，替代现在「回车才搜」）；Enter = 打开第一条结果；⌘Enter = 直接问 LMNotes。聚焦即临时进入结果态，清空恢复原视图。
2. **捕获行**（高 30px）：`[＋ 新笔记]`（带文字的紧凑按钮）+ `🎤 语音` + `📥 导入`（图标按钮）。`＋` 为主按钮点击直接创建**无标题草稿**（不再弹标题对话框，标题在编辑器内改）；存在模板时 `＋` 右侧出现 `▾` 展开模板菜单（含「空白笔记」项）。
3. **分段视图切换**（高 30px，三等分）：`笔记 | 标签 | 文件`，快捷键 ⌘1/⌘2/⌘3。
   - **笔记视图（默认）**：统一列表。无搜索时 = 按修改时间排序的笔记列表（行高 44px：标题 + 相对时间/路径）；有搜索时 = 结果列表（标题 + 摘要片段 + 路径 + 语义徽标），**首行固定为动作行**「✦ 问 LMNotes『query』」。标签过滤态在列表顶部显示可删除的标签 chip。
   - **标签视图**：现有 TagCloud 平铺（胶囊，按频率排序）；点击标签 → 切到笔记视图 + 标签过滤。
   - **文件视图**：现有 FileTree（行高 28px），交互不变。
4. **底部状态条**（高 32px，钉底）：`📚 库名` + 索引/LLM 健康小圆点（绿=健康，灰=禁用，点设置），右端搜索中 spinner。

### 3.3 主区与顶栏（Main + TopBar，44px）

**回答「读与写」**。顶栏三段：

- 左：**面包屑** `库 › 目录 › 笔记名`（当前笔记名用 `--text-1` 600 字重；父级目录 `--text-3` 可点跳转），后接状态：`● 未保存`（强调色）/`保存中…`/`已保存`（灰，2s 后淡出）、转录中/排队中 chip。
- 中：弹性空。
- 右：操作组（均为 30px 图标+文字按钮）：
  - **✦ AI 菜单**（下拉）：改写类（润色/扩写/翻译/总结，作用于选区，无选区时整篇）+ 抽取行动项（仅 `type: transcript|meeting` 显示）+ 每日/每周回顾。编辑器内右键 RewriteMenu 保留（选区上下文入口）。
  - **🕘 历史** → 打开右面板「历史」标签。
  - **预览/编辑** 切换。

历史快照、预览分屏等编辑器既有行为不变；CodeMirror 主题对齐新令牌（P3）。

### 3.4 右面板（Right Panel，0/300px，默认折叠）

**回答「我在审什么」**。标签式：`建议 | 历史`。入口：顶栏「🕘 历史」、顶栏右侧「✦ 建议 ③」计数 chip（替代永久右栏）、命令面板。浮起动画 180ms。建议项交互（接受/拒绝）不变，补键盘支持与 i18n kind 标签（摘要/标签/链接）。历史标签在 P2 由现 HistoryPanel（340px 浮层）迁入。

### 3.6 浮层体系（统一外壳）

四类模式，全部带标题栏（标题 + ✕）与 Esc 关闭：

| 模式 | 定位/尺寸 | z | 承载 |
|------|-----------|---|------|
| Popover | 锚定，min 160px | 100 | 右键菜单、✦ 菜单、模板菜单（视口边缘钳制） |
| Drawer | 右滑 100vh，Chat 480px / 图谱 640px 与全库 | 200 | 问答、图谱、（P2 前的）历史 |
| Dialog | 居中，560px（设置 720px），max-height 80vh | 300 | 捕获、语音、任务、时间线、确认框、Prompt |
| Palette | 顶部 12vh，min(600px,90vw) | 400 | 命令面板（置顶，万能逃生口） |
| Toast | 底部居中，堆叠，4s 自动消失 | 500 | 成功/错误反馈 |

统一规格：圆角 12（dialog/palette）、8（drawer/popover）；阴影 `--shadow-2`/`--shadow-1`；遮罩统一 `rgba(0,0,0,.45)`（暗）/`rgba(20,22,30,.25)`（亮）。设置对话框增加左侧分区导航（外观/通用/LLM 提供商/库/语音/备份/热键/数据）。**危险操作统一走新 ConfirmDialog**（替代 Tauri 原生 confirm）：清空聊天、恢复快照、取消运行中任务、删除文件、移除库。**关键失败路径接 toast**（替换纯 console.error）：保存、导入、改写、库切换、捕获。

### 4.3 主题插件系统（风格可插拔 + 动态切换）

主题 = 对 §4.1 颜色令牌的**声明式 JSON 覆盖**。插件是数据不是代码——无 JS 执行、无网络、无写权限（安全边界）。

**Schema（v1，`*.theme.json`，单文件 ≤ 64KB）**

```json
{
  "id": "warm-paper",          // ^[a-z0-9-]+$，全局唯一
  "name": "暖纸",               // 显示名（≤ 16 字符）
  "mode": "light",             // light | dark：决定阴影/滚动条/编辑器基调
  "colors": {                  // §4.1 颜色令牌子集；缺省键回退到同 mode 石墨预设
    "surface-0": "#f7f3ec",
    "surface-1": "#efe9df",
    "text-1": "#33302b",
    "accent": "#a3543a"
  }
}
```

校验：`id` 合法且唯一、`mode` 为枚举、颜色值须为 `#rrggbb` 或 `rgba()`。非法文件跳过并在设置·外观标警示，不阻塞启动（兜底 = 石墨）。圆角/密度/字体**不进** v1 schema——保持主题简单可验证，未来再扩展。

**来源**
1. **内置主题**（编译进代码的同 schema 预设，不可删）：石墨·暗（默认）、石墨·亮、暖纸·亮、墨黑·暗；
2. **用户目录** `~/.lmnotes/themes/*.theme.json`：新增 shell 层只读命令 `list_themes()` 扫描返回（在 `apps/desktop/src-tauri`，属 AGENTS.md 豁免区，不动 core）；启动加载 + 设置内「重新扫描」；目录 watch 热重载列为可选增强。

**应用与切换**
- `src/theme/index.ts`：`themes()` / `currentTheme()` / `setTheme(id)` signal；持久化 `localStorage lmnotes.theme`（与 `lmnotes.locale` 同模式）；
- 应用 = 对 `document.documentElement` 批量 `setProperty` 颜色令牌 + 设 `data-theme-mode` / `data-theme-id`；**切换即时生效、无重启**；
- `auto`（默认）= 跟随系统在石墨·暗/亮间切换（取代纯 `prefers-color-scheme` 媒体查询，tokens.css 全部挂 `[data-theme-mode]` 选择器）；
- 旧变量别名（`--bg` 等）由同一组令牌喂给，未迁移样式自动跟随换肤；
- CodeMirror 主题与滚动条挂钩 `data-theme-mode`；Cytoscape 配色去硬编码（P2 图谱节）。

**切换入口（两处，克制）**
1. 设置 · 外观：主题卡片网格（名称 + 5 色预览圆点 + 选中环 + 「跟随系统」卡 + 用户主题区含警示/重扫）；
2. 命令面板：「切换主题…」→ 主题列表，回车即切。

## 7. 状态设计与无障碍

- **空态**：上下文列表空 →「⌘N 新建第一条笔记」；搜索无结果 → 「无匹配 — ✦ 问问 LMNotes」；编辑器空 → 欢迎页（应用名 + 新建/导入/搜索三个入口 + 快捷键表，替代现在的灰字占位）；建议空 →「索引器会自动生成摘要/标签建议」。
- **加载**：搜索 spinner（状态条内）；编辑器/图谱/任务骨架行。LLM 生成中一律 ✦ 图标旋转 + 文案，不阻塞输入。
- **错误**：toast（danger 色）+ 可重试场景带「重试」按钮。
- **焦点**：`:focus-visible` 2px `--focus-ring` 外扩 2px；列表 ↑↓ + Enter 键盘导航；弹层打开焦点入内、关闭归还触发元素；rail 按钮带 `aria-label`。
- **对比**：正文/次文字/辅助文字全部 ≥ 4.5:1（双模式）；徽标底色用 `--accent-soft` + `--text-2` 文字。
